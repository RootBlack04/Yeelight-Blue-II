ℹ️ About

Stable local controller for Yeelight Blue II over Bluetooth Low Energy.

V14
🔵 Connection Web Bluetooth through Chrome. Refresh requires a normal Connect action.
🌈 Color Flow Built on the verified FFF7 flow path, with CB start and CE stop.
⚡ Energy Consumption is estimated from configured power, brightness and usage time.
Protocol safety: V14 does not introduce new undocumented BLE commands. The verified BLE core remains the foundation.
Developer Mode
Raw BLE diagnostics and protocol probes are kept here. Normal control should use the main tabs.
